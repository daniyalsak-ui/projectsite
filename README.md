# Звёздная степь

Многостраничный сайт о ночном небе над казахской степью.

- `index.html` — главная
- `moon.html` — фазы Луны
- `seasons.html` — небо по сезонам
- `baikonur.html` — Байконур
- `style.css`, `sky.js`, `moon.js`, `seasons.js`, `reveal.js` — общие стили и скрипты

Запуск: откройте `index.html` в браузере.
